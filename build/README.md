# build/

Recursos usados por `electron-builder` (ver `electron-builder.yml` en la raíz).

- **`icon.png`** (falta agregar): ícono de la app, cuadrado, idealmente
  1024×1024, PNG con fondo transparente si es posible. electron-builder
  genera automáticamente `.icns` (macOS) e `.ico` (Windows) a partir de
  este único archivo — no hace falta proveer los otros formatos.
